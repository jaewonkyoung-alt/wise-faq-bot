# 사용성 테스트 — 비개발자 관리자

**확인할 주장**: 개발 지식이 없는 관리자도 관리자 화면만으로 챗봇 데이터를 유지보수할 수 있다.

## 진행 방법

- 참가자: 프로그래밍 경험이 없는 학생 · 교직원 3~5명 (학과 조교 · 동아리 임원이면 가장 좋음)
- 장소 · 준비: 노트북 1대, `./scripts/setup.sh` 로 설치한 서버, 관리자 화면 로그인까지 진행자가 해 둠
- 진행자는 과제 카드만 건네고 **설명 · 도움 없이** 지켜본다. 막히면 3분 뒤 힌트 1회 (힌트를 준 과제는 '도움 받음'으로 기록)
- 과제마다 기록: 성공 여부 · 걸린 시간 · 틀린 클릭 · 참가자 발언
- 끝나고 SUS 설문(10문항, 5점 척도)과 짧은 면담

> 진행 전: 운영 DB 가 아니라 복사본으로 띄운 서버를 쓴다 (과제가 실제 데이터를 바꾼다).

## 과제

| # | 과제 카드 (참가자에게 주는 문장) | 성공 기준 | 목표 시간 |
|---|---|---|---|
| 1 | 컴퓨터공학과가 졸업기준 PDF를 새로 냈습니다. 이 PDF를 챗봇에 반영해 주세요. (PDF 파일 제공) | 졸업요건 → PDF 올리기 → 바뀐 칸 확인 → 적용 | 3분 |
| 2 | 방금 반영이 잘못됐다고 합니다. 원래대로 돌려 주세요. | 올리기 기록 → 되돌리기 | 2분 |
| 3 | 검도 동아리 「검선」의 정기 모임 시간이 "매주 화 · 목 18시"로 바뀌었습니다. 고쳐 주세요. | 동아리 → 검선 수정 → 저장 | 2분 |
| 4 | 동아리 3곳의 동아리방이 바뀌었습니다. 엑셀로 한꺼번에 고쳐 주세요. (바뀐 내용 표 제공) | 엑셀 내려받기 → 수정 → 올리기 → 미리보기 → 적용 | 6분 |
| 5 | 학생들이 "칼싸움 동아리"를 물어도 검도 동아리가 나오게 해 주세요. | 미답변 → 사전에 추가 (또는 동아리 → 키워드 사전) → 저장 | 4분 |
| 6 | 11월 30일까지 보여 줄 장학금 공지를 올려 주세요. | 공지 → 제목 · 본문 · 종료일 → 저장 | 3분 |
| 7 | 지난 공지가 사라졌다고 합니다. 찾아서 다시 보이게 해 주세요. | 공지 → 휴지통 → 복원 → 기간 고쳐 게시 | 4분 |
| 8 | 챗봇 데이터에 문제가 없는지 확인해 주세요. | 대시보드 → 데이터 점검 → 경고 읽고 설명 | 2분 |

각 과제 뒤 카톡(오픈빌더 봇 테스트 또는 휴대폰)에서 학생 입장으로 확인하면 "관리자 수정 → 카톡 반영"까지 한 번에 보여 줄 수 있다.

## 결과 정리 (논문 평가 장)

- 과제 성공률 (도움 없이 성공한 과제 / 전체), 과제별 평균 시간과 목표 시간 비교
- SUS 점수 평균 (68점 이상이면 평균 이상의 사용성으로 본다)
- 자주 막힌 곳 → 화면 개선 목록 (테스트 기간 10/26 ~ 11/1 에 반영)
