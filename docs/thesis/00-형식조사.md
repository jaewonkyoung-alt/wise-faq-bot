## 2. 공통점

**본문 흐름** — 6개 모두 같은 뼈대: **서론(배경 · 문제 · 목표) → 관련 연구 → 설계 → 구현 → (평가) → 결론**.

| 요소 | 등장 | 메모 |
|------|------|------|
| 국문 요약 + 주요어(키워드) | 6/6 | 주요어 최대 6개 (서울대) |
| 영문 제목 · 영문 초록 | 5/6 | 학위논문은 영문초록을 맨 뒤에 (서울대) |
| 관련 연구 · 기존 사례 비교 | 4/6 | 다른 대학 챗봇과 비교 표가 흔함 |
| 시스템 구성도 · 흐름도 | 6/6 | 그림 1개 이상은 필수처럼 쓰임 |
| 구현 화면 캡처 | 4/6 | 카톡 · 웹 화면 |
| **정량 평가** | **1/6** | 홍익대만 수치 비교. 나머지는 "만들었다"로 끝남 → **평가 장이 이 논문의 차별점** |
| 계획 대비 변경 · 미완료 사항 | 결과보고서(국민대) | 요구사항별 완료 / 변경 / 미완료와 이유 |
| 한계 · 향후 과제 | 6/6 | 결론에 포함 |
| 참고문헌 번호식 [1] | 6/6 | 저자, 「제목」, 학술지, 권(호), 쪽, 연도 |
| 부록: 매뉴얼 · 테스트 케이스 | 결과보고서 | 학위논문은 선택 |

## 3. 이 논문에 적용한 형식 (서울대 지침 기준, 학과 양식이 오면 교체)

- A4, 본문 10 ~ 30쪽, PDF 제출
- 여백: 위 30mm · 아래 15mm · 왼쪽 25mm · 오른쪽 25mm, 쪽번호 아래 가운데
- 본문 11pt 명조(바탕), 줄 간격 170%, 장평 100 · 자간 0
- 장 제목 16pt「제 1 장」, 절 제목 14pt「제 1 절」, 참고문헌 · Abstract 제목 16pt
- 표지: 국문 제목 24pt · 영문 제목 18pt · 지도교수 18pt · 「이 논문을 공학학사 학위논문으로 제출함」 20pt · 날짜 18pt · 학교 · 학과 · 이름 20pt
- 순서: 표지 → (인준지) → 국문초록 → 목차 · 표 목차 · 그림 목차 → 본문 6장 → 참고문헌 → 부록 → 영문초록
