# 개발환경 구축 · 형상관리

## 개발환경

| 항목 | 구성 |
|------|------|
| OS · 편집기 | macOS · VS Code (ESLint/TypeScript 확장) |
| 런타임 | Node.js 18 이상 (20 LTS 권장) · npm |
| 개발 실행 | `npm run dev` (tsx watch — 저장 시 자동 재시작) |
| 빌드 · 운영 | `npm run build` (tsc) → `npm start` (node dist/index.js) |
| DB | 최초 실행 시 자동 마이그레이션 + 시드(data/seed) |
| 검증 | `npm run typecheck` · `npm run test:*` · `npm run eval` |
| 공개 URL | cloudflared 터널 → 오픈빌더 스킬 URL 등록 |

## 구축 절차

1. `git clone` (private 레포)
2. `npm ci` — 잠금 파일 기준 설치
3. `.env.example` → `.env` 복사 · 토큰 설정
4. `npm run dev` — 마이그레이션·시드 자동
5. `GET /health` 로 상태 확인
6. `cloudflared tunnel` → HTTPS URL 발급
7. 오픈빌더 스킬 URL 등록 · 봇 테스트

## 환경변수

| 변수 | 용도 |
|------|------|
| PORT · DATABASE_PATH | 서버 포트 · SQLite 파일 경로 |
| ADMIN_TOKEN · KAKAO_SKILL_SECRET | 관리자 인증 · 스킬 호출 검증 |
| LLM_PROVIDER · *_API_KEY | mock / openrouter / openai / gemini |
| PUBLIC_BASE_URL | 카톡 PDF 링크용 공개 HTTPS 주소 |

## 형상관리 전략

| 항목 | 규칙 |
|------|------|
| 저장소 | GitHub private `jaewonkyoung-alt/wise-faq-bot` |
| 브랜치 | `main` = 발표·배포 가능 상태 / `feature/<기능>` → 자가 리뷰 후 main 병합 |
| 커밋 | `feat` · `fix` · `docs` · `test` · `chore` 접두어 + 한 줄 요약 |
| 태그 | 주간 발표 시점 태그(w3, w4 …) → 발표 내용과 코드 대응 |
| 비밀값 | `.env` · `*.db` 는 .gitignore, 예시만 `.env.example` |
| 백업 | GitHub 원격 + 외장 SSD 주 1회 복사 (SQLite 파일 포함) |
| 변경 통제 | 7주차(10/25) 이후 신규 기능 금지 → 버그픽스만 병합 |
