# WBS (Work Breakdown Structure)

프로젝트 전체 작업을 산출물 기준으로 분해한다. 자식 작업의 합은 부모 작업과 같다(100% 규칙).
간트차트는 이 WBS의 작업을 시간축에 배치한 것이다.

```
WISE FAQ 챗봇 프로젝트
├─ 1.0 기획·분석
│   ├─ 1.1 문제정의·대안 조사
│   ├─ 1.2 요구사항 정의(FR/NFR)
│   ├─ 1.3 유스케이스 도출
│   └─ 1.4 범위·일정 수립
├─ 2.0 설계
│   ├─ 2.1 시스템 구성·스택
│   ├─ 2.2 모듈·시퀀스·상태
│   ├─ 2.3 ERD·테이블 명세
│   └─ 2.4 API·화면 설계
├─ 3.0 구현
│   ├─ 3.1 카톡 스킬·대화 흐름
│   ├─ 3.2 졸업요건·지도 KB
│   ├─ 3.3 동아리 RAG·재색인
│   └─ 3.4 관리자 웹·공지 CRUD
├─ 4.0 테스트
│   ├─ 4.1 단위 테스트
│   ├─ 4.2 통합(API) 테스트
│   ├─ 4.3 카톡 E2E 시나리오
│   └─ 4.4 회귀·인수 테스트
├─ 5.0 배포·운영
│   ├─ 5.1 환경변수·보안 설정
│   ├─ 5.2 터널/서버 배포
│   ├─ 5.3 오픈빌더 스킬 연결
│   └─ 5.4 백업·레포 동기화
└─ 6.0 문서·발표
    ├─ 6.1 주간 발표 10회
    ├─ 6.2 설계 문서(docs)
    ├─ 6.3 운영 인수인계서
    └─ 6.4 최종 시연
```
