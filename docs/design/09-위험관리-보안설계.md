## 보안 설계 (시큐어 코딩)

| 항목 | 대응 |
|------|------|
| 인증 | 관리자 토큰 fail-closed · 상수시간 비교 · 라우트 단위 적용 |
| 입력 검증 | 필수값·숫자·URL 스킴(http/https) 검사 → 400 |
| SQL 인젝션 | prepared statement 바인딩만 사용 |
| XSS | 관리자 화면 출력 시 HTML 이스케이프 |
| 비밀값 | `.env` 분리 · .gitignore · 토큰 sessionStorage |
| 노출 최소화 | 카톡 오류 문구에 내부 경로·키 미포함 · 운영 시 CORS 제한 |

자세한 운영 점검 항목은 [../../SECURITY.md](../../SECURITY.md) 참조.
