### 확장 규칙(NFR-05) 검증

설계 시 세운 규칙은 "새 도메인 = 파일 3개 추가 + 기존 코드 1곳만 수정" 이었다.

- 신규: `src/types/notice.ts`, `src/services/noticeService.ts`, `src/routes/notices.ts`
- 수정: `src/db/database.ts`(테이블), `src/app.ts`(라우트 등록), `src/services/kakaoDialog.ts`(메뉴 분기 1곳)
- 기존 도메인(졸업요건·동아리·지도) 로직은 수정하지 않았다.

### 데이터 모델 (notices)

| 컬럼 | 타입 | 제약 | 설명 |
|------|------|------|------|
| id | TEXT | PK | UUID |
| title / body | TEXT | NOT NULL | 제목 · 본문 |
| link_url | TEXT | http(s)만 허용 | 원문 링크 |
| pinned | INTEGER | 0/1 | 상단 고정 |
| published | INTEGER | 0/1 | 게시 여부 |
| starts_at / ends_at | TEXT | NULL 허용 | 게시 기간 |
| created_at / updated_at | TEXT | NOT NULL | 생성 · 갱신 시각 |

인덱스: `(published, pinned, updated_at)` — 학생 조회 정렬 기준.

상태 판정: 게시 중(`published=1` + 기간 내) · 초안(`published=0`) · 예약(시작일 미래) · 종료(종료일 경과).

### 엔드포인트

| ID | Method | Endpoint | 인증 |
|----|--------|----------|------|
| API-07 | GET | `/api/notices?limit=5` | 없음 |
| API-17 | GET · POST | `/api/admin/notices` | 관리자 토큰 |
| API-18 | GET · PUT · DELETE | `/api/admin/notices/:id` | 관리자 토큰 |

응답 규약: 201 등록 · 200 조회/수정/삭제 · 400 필수값·링크 형식 오류 · 401 토큰 없음/불일치 · 404 대상 없음.
인증은 라우트마다 호출한다(`/api` 전역 미들웨어 금지 원칙 유지).

### 처리 흐름

- 관리자 등록: 관리자 웹 → `POST /api/admin/notices` → `checkAdmin` → 입력 검증(필수값·링크) → notices 저장
- 학생 조회: 카톡 '공지' → `POST /api/kakao/skill` → kakaoDialog 메뉴 분기 → `listPublishedNotices(5)` → `formatNoticesForKakao`(900자 클램프) → Skill JSON

## 3. 동작 확인

### 관리자 웹

- 공지 탭에서 등록·수정·삭제, 게시 여부·상단 고정·게시 기간 설정
- 목록에서 게시 중/초안/예약/종료 상태 확인
- 저장 전에 「카톡 미리보기」로 학생 화면 형식 확인 (서버와 같은 포맷 함수 사용)
- 대시보드 현황 카드에 공지 건수 반영

### 카카오톡

시연용으로 공지 4건(게시 3 · 초안 1)을 등록한 뒤 확인한 결과다.

| 항목 | 설계 규칙 | 실제 응답 |
|------|-----------|-----------|
| 정렬 | 고정 공지 우선, 그다음 최신순 | [고정] 장학금 안내가 첫 번째 |
| 건수 | 게시 중인 공지 상위 5건 | 등록 4건 중 3건 노출 |
| 초안 제외 | `published=0` 은 미노출 | '[초안] 겨울 계절학기'가 빠짐 |
| 링크 | http(s) 링크만 본문에 표시 | 장학금 공지에만 링크 표시 |
| 길이 | 총 900자 이내 클램프 | 259자 |
| 메뉴 복귀 | 응답 끝에 메뉴 버튼 재제시 | 졸업요건·동아리·지도·공지 4개 |

3주차까지 카톡 '공지'는 "등록된 공지가 없습니다" 고정 문구였고, 이번 주에 DB 조회 결과로 대체되었다.

### API

- 토큰 없이 관리자 API 호출 → `401 {"error":"unauthorized"}`
- `link_url: "javascript:alert(1)"` → `400 {"error":"link_url must start with http:// or https://"}`
- 공개 목록 `count = 3` (초안 제외)
- 카톡 스킬 응답: 259자, quickReplies 4개

| ID | 이슈 | 대응 | 시기 |
|----|------|------|------|
| R1 | 카톡 스킬 URL이 고정되지 않음 (터널 재시작 시 변경) | 고정 주소 확보 방안 비교 후 확정 | 5주 |

| R3 | 졸업요건 데이터가 PLACEHOLDER 예시값 | 학과 원문과 대조해 교체 (컴퓨터공학과 우선) | 5주 |
