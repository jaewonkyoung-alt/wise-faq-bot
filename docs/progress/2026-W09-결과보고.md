## 2. 결과물 요약 — 흩어진 학교 정보 -&gt; 카톡 한 곳 + 관리자 직접 갱신

- 1.  학생: 카카오톡 채널 하나에서 졸업요건 · 동아리 · 강의실 위치 · 공지 질문
- 2.  관리자(비개발자): 웹 화면에서 학교 PDF · 엑셀 올리기, 미리보기 -&gt; 적용 -&gt; 되돌리기
- 3.  생성형 모델 없이 데이터 그대로 답변 (출처 표시), 사전 밖 표현은 로컬 임베딩이 보완
- 4.  기능 요구사항 13개 모두 완료, 운영 서버(맥 미니 1대 + ngrok)로 10/10부터 상시 운영

| 메뉴 | 학생이 받는 답 | 관리자가 고치는 방법 |
|---|---|---|
| 졸업요건 | 학번 · 학과 · 학생구분별 공식 기준 (42개 학과) | 학과별 PDF 올리기 -&gt; 바뀐 칸만 미리보기 -&gt; 적용 |
| 동아리 | 자유 질문 -&gt; 소개 · 정기 활동 · 출처 (61곳) | 입력 칸 · 엑셀 일괄 수정 · 키워드 사전 · 미답변 보완 |
| 지도 | 호실 코드 · 건물 이름 -&gt; 위치 + 카카오맵 (287호실) | 학교 홈페이지 수집 데이터 |
| 공지 | 전교생 공통 공지 · 새 공지 알림 | 등록 즉시 반영, 기간 끝나면 자동 휴지통 |

## 3. 시스템 구성 — 카카오 스킬 서버 하나 + 관리자 화면

- 1.  카카오톡 -&gt; 오픈빌더 -&gt; ngrok 고정 주소 -&gt; 스킬 서버 (Node.js · TypeScript)
- 2.  데이터는 SQLite 파일 하나, 동아리 검색은 키워드 사전 + Ollama 로컬 임베딩
- 3.  관리자 화면은 같은 서버의 /admin, 이 컴퓨터에서만 접속
- 4.  PDF 표 추출 · 엑셀 변환은 Python 도구

- 4.  지도 · 공지: 호실 위치 + 카카오맵, 공지 알림 끄기 버튼

## 5. 관리자 화면 — 코드 수정 없이 데이터 수정 -&gt; 즉시 반영

- 1.  첫 화면에 '무엇을 어디서 고치나요?' 안내 + 미답변 · 데이터 점검 현황
- 2.  졸업요건 PDF · 동아리 엑셀은 바뀐 칸만 미리보기 후 적용, 잘못 올리면 되돌리기
