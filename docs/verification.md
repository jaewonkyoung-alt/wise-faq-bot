# 검증지표 (1차 발표 기준)

출처: `2021212843_경재원_1차발표.pptx` Slide 4 — 평가자 피드백으로 **측정방법** 열 추가.

## 최종 목표 (한 줄)

출처가 명시된 정확한 캠퍼스 정보 제공 + 비개발자가 웹 관리자 화면에서 데이터를 수정하면 별도 배포 없이 즉시 답변에 반영.

## 지표 표

| 번호 | 목표 (metric) | 검증지표 (target) | 테스트셋 (testset) | 측정방법 (measurement method) |
|------|---------------|-------------------|--------------------|-------------------------------|
| 1 | 동아리 도메인 질의응답 | 정답률 90% 이상 | 자체 동아리 QA 테스트셋 (정형·비정형 혼합) | 자체 테스트셋 정답 일치율 |
| 2 | 코드 수정 없이 신규 도메인 추가 | 개발작업 최소화·1시간 이내 | 신규 도메인 1건 추가 실측 시나리오 | 스키마 등록~질의 가능 실측 / **(권한·초기 인덱싱 예외)** |
| 3 | 비개발자 운영 가능 관리도구 | 수정 후 60초 이내 반영 | Admin 저장 후 동일 질의 재시도 | 저장→동일 질의 재시도 시간 |
| 4 | 환각 억제 | KB 없는 질문 오답률 5% 이하 | KB 미포함(OOD) 질문 세트 | 미포함 질문 세트 오답 생성 비율 |
| 5 | 정형 질의 정확도 | 수치형 질의 95% 이상 | 학점·가격·요일 등 수치/슬롯 질의 세트 | 학점·가격·요일 정답 일치 |
| 6 | 실용적 응답속도 | 평균 5초 이내 | 대표 질의 배치 (로컬/터널 환경 명시) | p50/p95 응답시간 |

## "신규 도메인 코드 0줄" 예외 (Slide 5)

발표 표현상 "코드 수정 없이 / 코드 0줄"에 가깝게 보이지만, **다음 작업은 예외로 인정**한다:

- 스키마(JSON) 등록
- 도메인 권한 설정
- 초기 인덱싱(임베딩 생성)

그 외 애플리케이션 코드 변경 없이 질의 가능을 목표로 한다.
