졸업요건 공식 기준 — 카카오톡 졸업요건 답변은 「2026 학사제도 및 학업이수가이드」에서 가져온 42개 학과 · 2020~2026학번 기준으로 나갑니다. 기준이 바뀌면 「졸업요건」 메뉴에서 학과 PDF를 올리고 미리보기를 확인한 뒤 적용하세요.
졸업요건을 저장하면 카카오톡 답변이 즉시 반영됩니다. (재인덱싱 불필요) 동아리는 저장 시 자동 재임베딩되며, 필요 시 전체 재인덱싱을 실행하세요.
폴더 지식베이스 — 경로 data/kb/ (졸업요건 / 동아리 / 지도). 폴더·파일을 추가한 뒤 KB 재스캔을 누르거나 서버를 재시작하면 반영됩니다. PDF는 /kb/... 로 제공되며, 카카오 버튼용 절대 URL은 PUBLIC_BASE_URL을 설정하세요.
