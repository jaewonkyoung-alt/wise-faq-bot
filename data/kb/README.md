# 지식베이스 폴더 (data/kb)

챗봇 답변에 쓰는 데이터 중 **파일로 두는 것**만 이 폴더에 있습니다.
졸업요건 공식 기준과 동아리 정보는 DB(SQLite)에 있고, 관리자 화면에서 고칩니다.

| 데이터 | 어디서 고치나 | 이 폴더에 있는 것 |
|---|---|---|
| 졸업요건 | 관리자 화면 「졸업요건」 → 학과 PDF 올리기 → 미리보기 → 적용 | `졸업요건/공식기준/<학과>.md` (적용할 때 자동 생성, 사람이 읽는 기록) · `_taxonomy.json` (단과대 → 학과) |
| 동아리 | 관리자 화면 「동아리」 → 입력 칸, 또는 엑셀 내려받기 · 올리기 | `동아리/_keywords.json` (검색 키워드 사전 — 관리자 화면에서 편집) · 수집 기록 |
| 지도 | 이 폴더의 JSON (학교 홈페이지 수집 도구로 다시 만듦) | `지도/buildings.json` · `rooms.json` · `places.json` |
| 공지 | 관리자 화면 「공지」 | — |

파일을 직접 고쳤다면 관리자 대시보드의 **데이터 점검**을 누르세요. 파일을 다시 읽고, 빠진 데이터가 있으면 무엇을 고쳐야 하는지 알려 줍니다.

## 졸업요건

- 공식 기준(42개 학과)은 학교 「학사제도 및 학업이수가이드」의 학과별 졸업기준 PDF에서 추출합니다.
- 새 기준이 나오면 관리자 화면에서 PDF를 올리면 됩니다. 학과를 자동으로 알아보고, 바뀌는 칸만 보여 준 뒤 「적용」해야 반영합니다.
- `졸업요건/<학과>/<입학연도>/info.md` (+ PDF) 폴더를 만들면 **공식 기준이 없는 학과에 한해** 보충 답변으로 씁니다.

## 동아리 키워드 사전 (`동아리/_keywords.json`)

학생이 동아리 소개와 다른 말로 물을 때 이어 주는 사전입니다. 예: "별 보는 동아리" → 분야 "천체" → 푸르체리마.
관리자 화면 「동아리」 아래 **검색 키워드 사전** 카드에서 단어를 쉼표로 적어 추가 · 수정 · 삭제합니다.
「미답변」에서 동아리 질문의 「사전에 추가」를 누르면 그 질문이 미리 채워집니다.

```json
{ "q": "별|천체|망원경", "c": "천체" }
```

- `q`: 학생이 쓰는 말, `c`: 동아리 소개(이름 · 분야)에 적힌 말. `c`를 비우면 `q`와 같습니다.
- `|`로 여러 단어를 잇습니다. `웹(?!툰)` 같은 예외 규칙이 있는 항목은 화면에서 '고급'으로 보이고 단어 편집은 막힙니다.

## 지도 (`지도/`)

- `buildings.json` 건물 코드 → 이름, `rooms.json` 호실 코드 → 건물 · 이름, `places.json` 건물 · 장소의 위도 · 경도.
- 학교 홈페이지에서 다시 수집하려면 `tools/map-crawl/crawl_campus_map.py`를 실행합니다. 자세한 내용은 `지도/README.md`.
- 예: `S504` → 자연과학관 5층 (앞 글자 = 건물, 숫자 첫 자리 = 층).

## 정적 URL

서버가 `data/kb`를 `/kb`로 제공합니다 (예: `/kb/졸업요건/공식기준/컴퓨터공학과.md`).
카카오 버튼용 절대 URL은 `.env`의 `PUBLIC_BASE_URL`을 사용합니다.
