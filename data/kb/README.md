# 폴더형 지식베이스 (data/kb)

관리자는 이 폴더 아래 구조를 맞추면 됩니다. 서버가 폴더를 스캔해 카카오 답변에 반영합니다.

## 최상위 폴더

| 폴더 | 용도 |
|------|------|
| `졸업요건/` | 학과 → 입학연도 → `info.md` + PDF |
| `동아리/` | 분과(카테고리) → 동아리명 → `info.md` |
| `지도/` | 건물 코드(`buildings.json`) · 호실 규칙 |

## 졸업요건 추가 방법

```
졸업요건/
  컴퓨터공학과/
    2022/
      info.md          # 카카오에 보여줄 텍스트
      졸업요건.pdf     # (선택) PDF — /kb/졸업요건/... 로 제공
```

1. 학과명 폴더를 만듭니다. (예: `경영학과`)
2. 그 안에 입학연도 폴더를 만듭니다. (예: `2022`, `2023`)
3. `info.md`에 학생에게 보여줄 요약을 적습니다.
4. PDF가 있으면 같은 폴더에 `*.pdf` 파일을 둡니다. (파일명 자유, 첫 PDF 사용)
5. 관리자 화면에서 **KB 재스캔**을 누르거나 서버를 재시작합니다.

카카오에서는 `info.md` 텍스트와 PDF 웹 링크 버튼을 함께 보여 줍니다.
(Open Builder는 PDF 바이너리를 스킬 JSON에 붙일 수 없어 `webLink`로 호스팅 URL을 엽니다.)

## 동아리 추가 방법

```
동아리/
  01_학술/
    와이즈코딩/
      info.md
  02_봉사/
  03_문화예술/
  04_체육/
  05_종교사회/
  _겹침/                 # 분과가 겹치는 동아리 (가능하면 여기 + 차이점 절)
    예시동아리/
      info.md
```

- 분과 폴더 이름은 `01_학술`처럼 번호+이름을 권장합니다.
- 겹치는 동아리는 `_겹침/`에 두고 `info.md`에 **차이점** 절을 적어 주세요.
- 현재 카카오 동아리 검색은 SQLite 시드와 병행됩니다. 폴더 내용은 문서·향후 동기화용입니다.

## 지도 (호실 코드)

`지도/README.md`와 `buildings.json`을 참고하세요.
예: `S504` → 자연과학관 5층 (앞 글자=건물, 숫자 첫 자리=층).

## 정적 URL

서버가 `data/kb`를 `/kb`로 제공합니다.

- 예: `/kb/졸업요건/컴퓨터공학과/2022/졸업요건.pdf`
- 카카오 버튼용 절대 URL은 `.env`의 `PUBLIC_BASE_URL`을 사용합니다.
