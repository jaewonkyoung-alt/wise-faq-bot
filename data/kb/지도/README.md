# 지도 · 호실 코드 규칙

동국대 WISE 캠퍼스 호실 코드(예: `S504`, `A207`)를 해석합니다.

## 규칙

1. **건물 코드** = 앞쪽 영문 (대소문자 무시). 여러 글자 코드를 먼저 매칭합니다. (`BST` → 백상탑)
2. **호실 번호** = 뒤쪽 숫자. `S-504`, `S 504`, `s504` 모두 허용.
3. **층** = 숫자부가 3자리 이상일 때 **첫 자리**. (`504` → 5층, `207` → 2층)
4. 건물 코드가 `buildings.json`에 없으면 **건물 이름을 추측하지 않습니다.**

## 예시 답변

- `S504` → `S504는 자연과학관 5층에 있어요.`
- `A207` → `A207은 원효관 2층에 있어요.`
- `ZZ999` → `ZZ 건물 코드를 찾지 못했습니다. …`

## 파일 (학교 홈페이지에서 자동 생성 — 직접 고치지 말고 크롤러를 다시 실행)

| 파일 | 내용 |
|------|------|
| `buildings.json` | 건물 코드 → 답변용 이름 (19개) |
| `places.json` | 캠퍼스맵 35곳: 코드 · 위도/경도 · 층수 · 준공 · 편의시설 · 소개 · 별칭 |
| `rooms.json` | 강의실 안내 287개 호실: 건물 · 호실명 · 구분 · 수용인원 |

```bash
python3 tools/map-crawl/crawl_campus_map.py            # 내려받아 다시 생성
```

- 건물 층수(지상)를 넘는 번호(예: D901 대강당, 100주년기념관은 지상 5층)는 층을 말하지 않습니다.
- 건물 이름 질문("도서관 어디야", "본관")은 `places.json`의 이름·별칭으로 찾고 카카오맵 링크를 붙입니다.
