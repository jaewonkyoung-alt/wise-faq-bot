# 지도 · 호실 코드 규칙

동국대 WISE 캠퍼스 호실 코드(예: `S504`, `A207`)를 해석합니다.

## 규칙

1. **건물 코드** = 앞쪽 영문 (대소문자 무시). 여러 글자 코드를 먼저 매칭합니다. (`BST` → 백상탑)
2. **호실 번호** = 뒤쪽 숫자. `S-504`, `S 504`, `s504` 모두 허용.
3. **층** = 숫자부가 3자리 이상일 때 **첫 자리**. (`504` → 5층, `207` → 2층)
4. 건물 코드가 `buildings.json`에 없으면 **건물 이름을 추측하지 않습니다.**

## 예시 답변

- `S504` → `S504은 자연과학관 5층에 있어요.`
- `A207` → `A207은 원효관 2층에 있어요.`
- `ZZ999` → `ZZ 건물 코드를 찾지 못했습니다. …`

선택적으로 `rooms.json`에 알려진 호실명을 넣으면 답변에 보강합니다.
(예: S504 → 공용강의실) 층·건물 판단은 여전히 규칙 기반이 우선입니다.
